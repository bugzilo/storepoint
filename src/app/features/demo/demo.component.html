Search Dropdown

stp-search-dropdown

Características del SearchDropdown

• #itemTemplate (Único template opcional): Personaliza cómo se dibuja cada fila con <ng-template #itemTemplate let-item let-active="isActive">.
• Footer Fijo: Muestra el conteo cuando excede el límite y/o la acción fija "Ver todo" habilitable mediante el booleano [showFooterAction]="true", emitiendo (footerClick).
• Sin Resultados: Fila 1 (ícono + mensaje). La opción de agregar o crear se habilita únicamente si se suministra el parámetro [actionLabel], emitiendo (action).

1. Plantilla Predeterminada (Máx. 5 Resultados)

size="md" • maxResults="5" (predeterminado) • sin templates custom

2. #itemTemplate (Único template opcional para maqueta personalizada)

{{ product.name }} {{ product.stock }} {{ product.unit }}
{{ product.category }} S/ {{ product.price.toFixed(2) }}
<ng-template #itemTemplate let-product let-active="isActive">
@if (selectedDropdownProduct(); as p) {
}

3. Footer con acción "Ver todo" habilitada por boolean y evento (footerClick)

[showFooterAction]="true" • acción fija "Ver todo" • evento (footerClick)
@if (footerNotification(); as notif) {
}

4. Sin Resultados con Acción (actionLabel configurado)

Fila 1: icono y texto • Fila 2: botón de acción habilitado por actionLabel
@if (registeredProductQuery(); as query) {
}

5. Sin Resultados Solo Informativo (sin actionLabel)

Sin actionLabel: solo se muestra el mensaje e ícono (sin botón de acción)
